# 答辩材料（**不进 zip**）

> 这个目录是**参赛者自己用**的：答辩前对着念、录视频时对着拍。
> 它**留在仓库里，但绝不进提交 zip**（`scripts/package.py` 的 `EXCLUDE_DIRS` 已挡）。
>
> 依据：赛题对 `ppt/` 的要求是「作品整体介绍 **PPT 或 PDF**，包含场景背景 / 功能架构 /
> 核心亮点 / 码道应用说明」——讲稿与分镜不在赛题要求里，所以从 `ppt/` 里分出来单独放。

## 目录里有什么

| 文件 | 用途 | 什么时候用 |
|---|---|---|
| `讲稿.md` | 18 页答辩逐页讲稿，约 4 分 50 秒（≤ 5 分钟） | 区域赛线上答辩（11/21–11/27） |
| `视频分镜.md` | 3 分钟演示视频逐镜头表（9 镜 / 175 秒），与 `docs/演示脚本.md` 对齐 | **录视频时**（这是录屏的操作手册） |

## 它们去哪了

打包时 `scripts/package.py` 会按 `codearts_proof/zip-layout.md` 的规划**投放副本**进 zip：

| 源文件 | 投放位置 | 为什么 |
|---|---|---|
| `讲稿.md` | `ppt/讲稿.md` | 评委可对照 PPT 读 |
| `视频分镜.md` | `ppt/视频分镜.md` **和** `video/视频分镜.md` | 评委可对照视频读"这视频确实是照着这个拍的" |

**源只有这一份**，打包时复制出去 —— 不维护两份真相，改一处就够。

> 不想让评委看到讲稿？删掉 `scripts/package.py` 投放块里的
> `("讲稿.md", ("ppt",))` 那一项即可，其余不受影响。

## 录视频时看什么

- **分镜表看这里**（`视频分镜.md`）：9 个镜头、每镜的操作 URL 与旁白词都是现成的
- 录屏环境：`python scripts/ctl.py serve` → 浏览器 **1920×1080**
- 官方口径 URL（别用首页透传）：`http://localhost:8000/plan.html?days=3&budget=3000&tags=美食,文化&auto=1`
- 第 9 镜要念的旁白词**已按 03L 更新**（19 份任务单 / 24 轮 / 139 测试 / 冒烟 23 步），
  改动记得同步回 `docs/演示脚本.md`（两边是同一份内容，**改一处要改另一处**）

# 华为云接入说明

> 三条接入线**全部可选、可降级、不配置不影响主流程**——这是「断网保命」设计的边界。
> 实现层：`server/cloud/`（独立成层，评委一眼可见）。速查表见 `server/cloud/README.md`。

## 一、OBS 对象存储（行程持久化）

- **用途**：把规划产物 JSON 上传 OBS，形成可分享的行程档案
- **环境变量**：`OBS_ENDPOINT` / `OBS_BUCKET` / `OBS_AK` / `OBS_SK`（可选 `OBS_REGION`，默认 cn-north-4）——**四个齐全才启用**
- **实现**：`server/cloud/obs.py`，标准库 `http.client` + S3 兼容 SigV4 签名，**零新依赖**
- **未配置行为**：`save_plan()` 返回 `{"enabled": false, "reason": "未配置 OBS 环境变量，已跳过"}`，主流程零影响
- **调用端点**：`POST /api/plan/{plan_id}/save`
- **事件可见**：调用前后发 `system/tool_call` + `system/tool_result` 事件——评委在可倒带时间轴上直接看到"这里接了华为云"与降级原因
- **验证方法**：配置后调用 save 端点，返回 `ok: true` + `url`；或看时间轴 tool_result 事件

## 二、FunctionGraph 函数计算（天气数据源）

- **用途**：把 `weather` 工具的数据源从本地快照切到 FG 函数（演示「数据层可接 OTA/云端」）
- **环境变量**：`FG_WEATHER_URL`（存在即启用）
- **实现**：`server/cloud/functiongraph.py`，标准库 `urllib.request` POST，**2s 超时**
- **未配置/超时/失败行为**：静默回落本地快照（`source=local-snapshot`），绝不拖慢或打断管线
- **验证方法**：规划事件流的 `weather` tool_result 中 `source` 字段
  （functiongraph=已接云端 / local-snapshot=本地兜底）
- **预留话术**：接口形态已按「换数据源不改管线」设计——`weather.py` 只换 `_fetch` 一层

## 四、答辩演示口径

1. 断网/无任何配置 → 完整可演示（本地快照 + 离线管线 + Mock 前端兜底）
2. 配 OBS 四变量 → save 端点真实上云，时间轴留痕
3. 配 FG_WEATHER_URL → 天气走云端函数，超时静默回落
4. 三态切换本身就是「可选增强」的现场演示素材
## 五、ECS 部署注意事项

- **必须单 worker**：`uvicorn server.app:app --workers 1`——`/api/revise` 依赖进程内
  计划缓存（`_PLANS` dict），多 worker 下 plan 与 revise 落到不同进程会 404
  （「对话改行程」演示项当场失效）。单机演示场景下的刻意取舍，不是缺陷
- **在线模式默认关闭**：公网部署即使 `.env` 残留 `DEEPSEEK_API_KEY`，auto 模式下
  须显式 `SD_ALLOW_ONLINE=1` 才走在线（防止他人调用烧 API 额度）；配套 IP 限流
  （在线模式每 IP 每秒 5 次，超限 429）与输入长度上限（422）。详见 `readme/README.md` 公网防护一节

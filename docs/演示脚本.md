# 演示脚本（3 分钟视频逐镜头表）

> 与 `ppt/视频分镜.md` 对齐；录屏环境：`python scripts/ctl.py serve` + 浏览器 1920×1080。
> URL 直达参数可避免现场输入：`http://localhost:8000/?days=3&budget=3000&tags=美食,文化&auto=1`

| 镜号 | 时长 | 画面 | 操作 | 字幕/旁白要点 |
|---|---|---|---|---|
| 1 | 0:00–0:15 | 首页全页（瑞士网格版式入场动效） | 打开 URL（auto=1 自动跑） | 「蜀道智行：把 Agent 的决策过程做成可回放的产品」；指出 H1/数字块 40 POI·2 城·3 段 |
| 2 | 0:15–0:35 | 双城地图 + 点位落位动画 | 鼠标悬停宽窄巷子看 tooltip | 「本地快照 40 点厚字段——开放时段/预约难度/爬坡强度，都是决策依据」 |
| 3 | 0:35–1:05 | **底部抽屉展开**：Agent 决策回放 | 点顶栏「Agent 决策回放」按钮 | 三列事件日志：序号/标题/**原因**；「每一次选点都说得出为什么」 |
| 4 | 1:05–1:35 | **可倒带时间轴**（核心差异化） | 拖进度条到「第2天选点」事件，再拖回开头 | 地图点位/行程卡随进度条同步回退/点亮；「回放到任何一步，看它当时怎么想的」 |
| 5 | 1:35–2:00 | 修复回流叙事 | 改参数跑夜景场景（`?days=2&budget=2000&tags=夜景&auto=1`） | violation 红标 → fix 事件 → 地图点位**变灰打叉** → 行程卡「✕ 被规则移除」→ pass；「LLM 规划 + 规则校验，违规自动回流修复」 |
| 6 | 2:00–2:25 | **对话式改行程** | 输入「第二天太赶」发送 | 抽屉出现「用户介入」第二幕；第 2 天 5→4 点、负载下降；「自然语言改行程，过程同样可回放」 |
| 7 | 2:25–2:45 | 断网保命演示 | 停掉后端进程 → 刷新页面 | 徽标「本地演示数据（后端未启动）」，全部功能照常；「答辩现场断网，照样完整演示」 |
| 8 | 2:45–3:00 | 工程全景收尾 | 快速滚动 `git log`（[prompt NN] 轨迹）与 docs/ 目录 | 「全程码道开发，11 轮任务单 + 先红后绿调试记录可查；60 测试 + CI 三连」 |

## 录制注意

- 镜 4 的回放拖动要**慢**：观众需要看清地图点位随进度条逐步点亮的过程
- 镜 5 先停录换参数再录（或用剪辑衔接），两场景 URL 见表
- `prefers-reduced-motion` 用户看不到入场动效——录屏机器确认系统动效开启

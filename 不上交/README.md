# 不上交（**留在仓库里，但绝不进 zip**）

> 这个目录是"**该留在本机、但不该让评委看到**"的专用区。
> 它**不进提交 zip**（`scripts/package.py` 的 `EXCLUDE_DIRS` 已挡），但仍然在 git 里——
> 所以证据链不丢，只是提交包里干净。

## 现在里面有什么

| 路径 | 是什么 | 为什么不上交 |
|---|---|---|
| `赛题抓取存档/` | 大赛官网抓取的**原始 JSON**（`comp_tabs.json` 106KB 等）——原料，非作品材料；有用的原文已整理进 `docs/赛题情报/` | 原料 ≠ 作品材料 |
| `已废弃脚本/` | 清理出来的旧脚本（`ci.sh` / `ci.bat`）+ 一份 README 说明为什么废弃、引用已同步到哪 | 已被更好的实现取代，且旧实现**更弱**（会吞掉 lint 失败） |

> `docs/赛题情报/` 里留的是**赛题与评分标准原文**（4 个 txt），那个**要上交**——
> 让评委能核对我们对赛题的理解（分区范围、提交规范、评分权重逐条对齐）。

## 以后什么东西该放这里

- **原始录屏素材**：多take 的视频、录屏前的废弃片段、原始截图
  （成片才放 `video/`，多余的别进包）
- **临时导出物**：临时 PDF、导出中间文件
- **本地私密配置**：`~/.netrc` 类的、任何带 token 的草稿
  （注意：`.env` 由 `package.py` 的 `EXCLUDE_FILES` 单独挡，**不要**把它挪到这里——
  本地运行要读它，挪走在线分支就废了）

## 纪律

1. **进这个目录的东西，提交前确认一遍**——它不进包，但它进 git。
2. **不放任何密钥**。真要放，先确认 `package.py` 的密钥扫描不会漏（它扫的是 staging，
   不扫这里，所以这里的东西**根本不会进包**，密钥泄漏风险仅限 git 历史）。
3. **不放过程证据**。`codearts_proof/` 里的东西**全部要上交**——那是 25 分「码道深度使用」
   的原始素材，不许挪到这里。

## 生成方式

```
# .env 需含：DEEPSEEK_API_KEY=…（不入库）与 SD_ALLOW_ONLINE=1（公网防护开关，本地/答辩用）
python cli.py --days 3 --budget 3000 --tags 美食,文化
```

- 命令与生成时间写在文件头；SHA-256 全文摘要见 debug-log 第十七轮
- 在线模式为非确定性（temperature 0.3）：同一命令两次运行的选城可能不同（v1.1.6 已如实记录），
  本存档是其中一次真实运行；答辩需要确定性输出时切 `SD_LLM_MODE=offline`
- 存档前已确认输出不含任何密钥字样（`DEEPSEEK` / `sk-` 全文检索为零命中）

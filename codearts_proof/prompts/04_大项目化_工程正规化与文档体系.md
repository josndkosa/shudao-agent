- ✅ **加"骨架"**：版本控制、依赖管理、文档、目录规范、测试入口、提交流水线

### C2. 跨平台任务入口 `scripts/ctl.py`

Windows/macOS/Linux 都能跑，**不要用 Makefile**（Windows 未必装了 make）：

```bash
python scripts/ctl.py test        # pytest
python scripts/ctl.py lint         # ruff check（若未装 ruff 就跳过并提示）
python scripts/ctl.py smoke       # node scripts/smoke_frontend.mjs
python scripts/ctl.py assets      # 重新生成 static/demo*.json
python scripts/ctl.py serve       # 启动 uvicorn
python scripts/ctl.py ci          # 依次跑 lint + test + smoke
python scripts/ctl.py package     # 组装提交 zip（见任务 F）
```

每个子命令都要有清晰的输出与正确的退出码。

### C3. CI 脚本（**不要写假的 GitHub Actions 配置**）

赛题用华为云，**不要**硬凑 `.github/workflows/`。改为：

- `scripts/ci.sh` / `scripts/ci.bat`：依次跑 lint → test → smoke，任何一步失败即非零退出
- 在 `docs/华为云接入说明.md` 或 readme 里写明：「本项目 CI 已脚本化，可直接接入华为云 CodeArts 流水线」

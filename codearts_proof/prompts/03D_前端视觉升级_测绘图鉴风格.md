# 码道 Prompt 03D · 前端视觉升级：《西南测绘图鉴》风格重构

> 用法：整段粘贴给码道（IDE 模式）。前置：Prompt 03B / 03C 已完成。
>
> **这是一次纯视觉重构**：功能、文案、数据结构、交互逻辑**一律不动**。
> 目标是把现在这版"通用深色仪表盘"换成一份**有明确美学主张的旅行测绘图鉴**。

---

## 一、为什么现在的界面显得简陋（先对齐认知）

现状 `static/style.css` 的配色是 GitHub Dark 原版四件套：
`--bg:#0E1116 / --panel:#161B22 / --border:#30363D / --fg:#E6EDF3`，
加上"**填充面板 + 1px 实心边框 + 8px 圆角**"的通用组合。

这不是"没做好"，是**没有美学主张**——换成任何一个后台项目都是这个样子，评委一眼能认出是 AI 生成的默认深色仪表盘。

**本次要建立的方向**：把产品做成一份**精密的西南旅行测绘图鉴**（Survey Atlas）——
像一本有图廓、有刻度、有等高线、有图例的地图册，而不是一个管理后台。

---

## 二、硬约束（违反即返工）

1. **零外部资源**：不引 CDN、不引 webfont、不引图标库、不引外链图片。
   字体只用**系统本地字体栈**；纹理/图案用 CSS 渐变或内联 SVG data-uri。
2. **不改功能**：不改 `api.js` / `main.js` / `map.js` / `timeline.js` 的任何逻辑。
   `player.js` **一行都不许改**（时间轴节点用 CSS 伪元素实现，见第五节）。
3. **不改 class 名**：现有 class 名是 JS 的契约，**只允许新增 class**，不允许重命名或删除。
4. **不改文案与数据**：一句文案、一个数字、一个图标都不要改。
5. **1366×768 不塌**，1920×1080 要更好看。
6. **保留 `prefers-reduced-motion` 降级**（现有那段媒体查询要保留并扩展）。
7. **动画只用 CSS transition/animation 或 Web Animations API**，不引 GSAP/anime.js。

## 三、设计系统：色 / 字 / 尺度

### 3.1 色彩 —— 换成"墨色纸面 + 分层设色"

**删掉** GitHub Dark 四件套，改用下面这套（写成 CSS 变量，**变量名保持不变**，只改值，避免动 JS）：

```css
:root {
  /* 墨色纸面（不是纯黑，带一点冷调，模拟图纸底） */
  --bg:        #0A0E13;   /* 页面最底 */
  --panel:     #10161E;   /* 面板 */
  --border:    #1E2833;   /* 细标注线（不是"边框"，是图纸上的线） */
  --fg:        #E8EDF2;   /* 主文字：冷调纸白 */
  --fg-dim:    #9AA7B4;   /* 次要文字 */
  /* 城色：成都赭橙 / 重庆江青 */
  --cd:        #E5A14A;   /* 成都 */
  --cq:        #5FB0D6;   /* 重庆 */
  /* 状态色（略微提亮，暗底上要够清晰） */
  --bad:       #E5645E;
  --ok:        #6FBF73;
  --tool:      #A98BE0;
  --warn:      #E0A33E;
  --unfix:     #DB6D28;
}
```

**关键**：层次**不再靠"填充 + 边框"**，而是靠**色阶 + 细线 + 高光**。
面板统一用：
```css
background: linear-gradient(180deg, rgba(255,255,255,.022), transparent 60%);
box-shadow: inset 0 1px 0 rgba(255,255,255,.035);
border: 1px solid var(--border);
```
（有一道极淡的顶部高光，像图纸压印上去的层次）

### 3.2 字体 —— 标题用衬线，立刻脱离"后台系统感"

**中文衬线**（Windows / macOS 都有，无需下载）：

```css
--font-display: "Source Han Serif SC", "Noto Serif CJK SC", "Songti SC",
                 "STSong", "SimSun", Georgia, serif;
--font-body:    "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui, sans-serif;
--mono:         ui-monospace, "SF Mono", "JetBrains Mono", "Cascadia Mono", Consolas, monospace;
```

应用规则（**这是本次视觉升级最重要的一条**）：

| 元素 | 字体 | 说明 |
|---|---|---|
| 顶栏品牌「蜀道智行」 | `--font-display`，22px，字重 600 | 衬线中文立刻有"出版物"感 |
| 地图卡城市名（成都/重庆） | `--font-display`，24px，字距 6px | 图幅标题 |
| 区块标题（Agent 决策回放） | `--font-body`，13px，字重 600，**字距 3px，全大写或加宽** | 图鉴章节名 |
| 景点名 | `--font-display`，13.5px | 条目名 |
| 叙事文案 | `--font-display`，13px，行高 1.9 | 引文感 |
| 所有时间 / 序号 / 坐标 / 数字 | `--mono` + `font-variant-numeric: tabular-nums` | 测绘仪器的读数感 |
| 辅助说明 / reason | `--font-body`，12px | |

### 3.3 尺度与间距

- 字号阶梯拉开：`11 / 12 / 13.5 / 15 / 18 / 22 / 24`
- 行高：正文 1.75，密排的事件列表 1.5
- 间距用 4 的倍数：`4 / 8 / 12 / 16 / 24 / 32`
- 圆角**收敛**：只有输入框与徽章用 4–6px，**面板一律 2px**（图纸不该是圆的）

## 四、背景与质感（"图纸"从哪来）

### 4.1 页面底纹：等距坐标网格

`body` 叠两层极淡的网格（模拟图纸坐标底纹）：

```css
body::before {
  content: ""; position: fixed; inset: 0; pointer-events: none; z-index: 0;
  background-image:
    repeating-linear-gradient(0deg,  rgba(255,255,255,.014) 0 1px, transparent 1px 32px),
    repeating-linear-gradient(90deg, rgba(255,255,255,.014) 0 1px, transparent 1px 32px);
}
body::after {  /* 更粗的一级网格 */
  content: ""; position: fixed; inset: 0; pointer-events: none; z-index: 0;
  background-image:
    repeating-linear-gradient(0deg,  rgba(255,255,255,.02) 0 1px, transparent 1px 160px),
    repeating-linear-gradient(90deg, rgba(255,255,255,.02) 0 1px, transparent 1px 160px);
}
```

> 注意：`body` 现有 `display:flex` 布局不变，伪元素用 `position:fixed` 不占布局。
> **`.topbar` / `.layout` / `.chat-bar` 需要 `position:relative; z-index:1`**，否则会被网格压住。

### 4.2 图廓角标

每个主要面板（`.params` / `.map-card` / `.days` / `.right`）加**四角定位角标**（像制图软件的图廓角）：

```css
.panel-frame { position: relative; }
.panel-frame::before, .panel-frame::after {
  content: ""; position: absolute; width: 10px; height: 10px; pointer-events: none;
  border-color: rgba(229,161,74,.5); border-style: solid; border-width: 0;
}
.panel-frame::before { top: 6px; left: 6px;  border-top-width: 1px; border-left-width: 1px; }
.panel-frame::after  { bottom: 6px; right: 6px; border-bottom-width: 1px; border-right-width: 1px; }
```
（用 **新增** class `panel-frame` 加在 HTML 上，不要覆盖 `.params` 等已有类）

### 4.3 顶栏

- 去掉实色 `--panel` 底，改成**透明 + 底部一条双色渐变细线**（成都赭橙 → 重庆江青），呼应双城
- 品牌字用衬线 + 渐变裁切（现有 `background-clip:text` 保留，字号放大到 22px）
- 徽章改成**刻度牌**样式：细边框 + 方角（2px 圆角）+ 等宽小字

## 五、双城地图卡 = 测绘图幅（视觉升级重点）

### 5.1 经纬网

在 `.map-svg` 上叠一层极淡的经纬网（`.map-svg` 需 `position:relative`，网格层 `pointer-events:none`）：

```css
.map-svg::before {
  content: ""; position: absolute; inset: 0; pointer-events: none;
  background-image:
    repeating-linear-gradient(0deg,  rgba(255,255,255,.028) 0 1px, transparent 1px 28px),
    repeating-linear-gradient(90deg, rgba(255,255,255,.028) 0 1px, transparent 1px 28px);
  mask-image: radial-gradient(ellipse at center, #000 40%, transparent 92%);  /* 中心密、边缘淡 */
}
```

### 5.2 图廓要素（**加在 `index.html`，纯静态，不用 JS**）

每个 `.map-card` 里加：

```html
<div class="map-frame">
  <div class="map-title"><span class="city-cn">成都</span><span class="city-meta">CHENGDU · 30.67°N 104.07°E</span></div>
  <div class="map-scale"><span class="bar"></span>10 km</div>
  <div class="compass"><span>N</span></div>
</div>
```

- `.city-cn`：衬线 24px，字距 6px，城市主色
- `.city-meta`：等宽 9.5px，`--fg-dim`，大写
- `.map-scale`：左下角，刻度条（用 `repeating-linear-gradient` 画齿）+ 等宽文字
- `.compass`：右上角，纯 CSS 三角 + "N"

### 5.3 SVG 内容

- 路线线：保持实线，但当前天的线加 `stroke-linecap:round` + **一层更淡的同路径底线**（`stroke-width` 大 3px、透明度低），像地图上的"道路底图"
- 非当天的线：改成**虚线**（`stroke-dasharray: 3 5`）而非单纯降透明
- marker：`must_see` 的地标改为**双环 + 中心实点**（已有外圈，中心再加一个小点）
- marker 新出现时：从 `scale(.2) → scale(1)` + 一圈扩散环（用 CSS `@keyframes` + `box-shadow` 动画）

## 六、事件流 = 决策日志（**本产品的灵魂，必须是全场视觉焦点**）

现状是"灰色列表"。要改成**垂直时间轴**。

> **约束：`player.js` 一行都不许改。** 以下全部用 CSS 伪元素实现。

### 6.1 时间轴结构

```css
.evt { position: relative; }
/* 贯穿整列的连接线（在图标列正中） */
.evt::before {
  content: ""; position: absolute; left: 55px; top: 0; bottom: 0; width: 1px;
  background: linear-gradient(180deg, transparent, var(--border) 12%, var(--border) 88%, transparent);
}
.evt:first-child::before { top: 50%; }      /* 首条：线只往下 */
.evt:last-child::before  { bottom: 50%; }    /* 末条：线只往上 */
/* 节点：把图标变成圆环（border 用当前 type 颜色） */
.evt-icon {
  position: relative; z-index: 1;
  width: 18px; height: 18px; border-radius: 50%;
  display: grid; place-items: center;
  background: var(--panel); border: 1px solid currentColor;
  font-size: 10px; line-height: 1;
}
```

> `.evt` 现在是 `grid-template-columns: 44px 18px 1fr`，图标列中心大约在 `44 + 9 = 53px`，
> 连接线 `left` 请按实际渲染微调（用 52–56px 之间），保证线正好穿过节点圆心。

### 6.2 当前事件（焦点）

```css
.evt.cur {
  background: linear-gradient(90deg, rgba(229,161,74,.10), transparent 70%);
  border-left: 2px solid var(--cd);
}
.evt.cur .evt-icon { box-shadow: 0 0 0 3px rgba(229,161,74,.18); transform: scale(1.12); }
```

### 6.3 reason 变成"引用块"

现状是灰色小字。改成**左侧细线缩进的引用块**——这是全场最重要的文字，要能被一眼扫到：

```css
.evt-reason {
  color: var(--fg-dim); font-size: 12px; line-height: 1.65;
  border-left: 2px solid var(--border);
  padding: 2px 0 2px 10px; margin-top: 3px;
}
.evt.cur .evt-reason { color: var(--fg); border-left-color: var(--cd); }
```

### 6.4 阶段标签

现在的彩色文字 `[plan]` 改成**小色块标签**（方角、微底色）：

```css
.evt-stage {
  display: inline-block; font-size: 9.5px; letter-spacing: .6px; padding: 1px 5px;
  border-radius: 2px; background: currentColor; /* 用 color-mix 降透明度 */
  color: var(--cq);
}
```
（用 `color-mix(in srgb, currentColor 16%, transparent)` 做底色，保持各 stage 的色相）

### 6.5 序号与未来态

- `.evt-seq`：等宽 10px，`--fg-dim`，靠左
- `.evt.future`：不只是降透明，改为 `filter: saturate(.25); opacity:.3;`（去饱和更像"未发生"）

## 八、动效编排（要有节奏，不要散）

### 8.1 一次性入场（`animation-delay` 编排）

```
顶栏        0ms
参数条      60ms
成都图      120ms
重庆图      200ms（与成都错开 80ms）
高铁连线    260ms
行程区      300ms
事件日志    340ms，事件逐条 stagger 22ms
```

统一用 `@keyframes riseIn { from { opacity:0; transform: translateY(10px); } }`，
配合 `animation-fill-mode: both`。

> stagger 用 CSS 实现，不要改 JS：`.evt-list > .evt:nth-child(n) { animation-delay: calc(340ms + var(--i) * 22ms) }`
> 若拿不到序号，用 `:nth-child` 写前 20 条即可（超过 20 条的靠 `animation-delay` 继承）。

### 8.2 地图路径描绘

`.route-line` 用 `stroke-dasharray` + `stroke-dashoffset` 动画，1.1s `ease-out`，
从起点画到终点（用 pathLength 归一化或大数值 dasharray 均可）。

### 8.3 回放联动

- 新事件到达时，节点圆环**脉冲一次**（`box-shadow` 扩散 + 淡出）
- 当前事件切换时，`.evt.cur` 的背景有 200ms 过渡
- 地图 marker 高亮：沿用现有 `highlight()` 的 Web Animations，**视觉上改成"扩散环"而非缩放**

### 8.4 降级

现有 `@media (prefers-reduced-motion: reduce)` 保留，并把所有新动画纳入：
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important; animation-delay: 0ms !important;
    transition-duration: .01ms !important;
  }
}
```

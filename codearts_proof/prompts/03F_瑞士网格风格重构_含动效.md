## 一、方向：瑞士国际主义版式（Swiss / International Typographic Style）

**这不是"深色仪表盘换浅色"**，是一套完整的排版纪律：

| 原则 | 具体要求 |
|---|---|
| **网格至上** | 12 栏网格，所有内容严格对齐栏位；不是"看起来对齐" |
| **字号对比** | 极端的大小反差（标题 66px / 正文 15px / 辅助 11px），靠字号建立层级，**不靠颜色和边框** |
| **无装饰** | **零圆角、零阴影、零渐变、零毛玻璃、零图标字体、零 emoji** |
| **横线即元素** | 分隔靠 1px 实线/浅灰线，线条是版面的骨架 |
| **单一强调色** | 全站只有一种强调色（朱红），**其余全是黑/白/灰** |
| **字体即排版** | Helvetica 系（西文）+ 系统中黑（中文）+ 等宽（数字）。**不要衬线** |

### 配色（直接照抄 `b-swiss.html` 的 `:root`）

```css
:root{
  --bg:#FFFFFF; --ink:#000000; --ink2:#5A5A5A; --ink3:#9B9B9B;
  --rule:#E4E4E4; --rule2:#F0F0F0; --accent:#E5484D; --drawer:#FFFFFF;
  --sans:"Helvetica Neue",Helvetica,"PingFang SC","Microsoft YaHei",Arial,sans-serif;
  --mono:ui-monospace,"SF Mono",Consolas,monospace;
}
```

**只有一个强调色**。城市色（成都橙 / 重庆蓝）**全部去掉**——瑞士风格里两个城市色是杂质。
成渝的区分靠**位置**（左成都 / 右重庆）和**标签文字**，不靠颜色。

### 字体与尺度

- 标题：`--sans`，`font-weight:700`，`letter-spacing:-2.4px`（大标题）/ `-0.8px`（次级标题）
- 正文：`--sans` 15px / `line-height:1.6`
- 辅助与说明：`--sans` 13.5px / `--ink2`
- **所有数字、时间、序号、价格**：`--mono` + `font-variant-numeric: tabular-nums`
- 圆角：`0`（输入框与按钮也是 `border-radius:0`）
- 阴影：`none`（全部）

## 三、动效编排（**本次的第二个重点**）

瑞士风格的动效语言：**精准、几何、有秩序、无装饰**。不要柔和模糊缩放，要**位移与线条**。

### 3.1 入场编排（一次性，按时间轴推进）

| 时间 | 元素 | 动效 |
|---|---|---|
| 0ms | 顶栏 | 从上方 `-8px` 落下 + opacity 0→1，320ms |
| 60ms | **H1 大标题** | **字距从 `-12px` 收紧到 `-2.4px`** + opacity 0→1，620ms，`cubic-bezier(.16,1,.3,1)` |
| 200ms | 副标题 | 从下 `10px` 上移 + opacity，380ms |
| 260ms | 4 个数字块 | 逐个从下 `12px` 上移，stagger **70ms** |
| 380ms | 参数条 | 横向 1px 线从左 scaleX 0→1 画出 + 内容淡入，420ms |
| 460ms | 双城图框 | 左右两幅分别从两侧 `±16px` 滑入，stagger **90ms**，480ms |
| 620ms | **地图点位** | 逐个落位：`scale(.2)→scale(1)`，stagger **38ms**，260ms，`cubic-bezier(.34,1.4,.64,1)`（轻微回弹） |
| 640ms | **地图路线** | `stroke-dashoffset` 从全长到 0，**900ms** `ease-out`，与点位落位同步 |
| 900ms | Day tabs | 底部黑线从左 scaleX 0→1 画出，340ms |
| 1000ms | 行程条目 | 逐条从下 `10px` 上移 + opacity，stagger **28ms** |
| 1250ms | 负载条 / 预算条 | 从左 scaleX 0→1 画出，320ms |

> **点位与路线的先后**：先描线（640ms）→ 点位依次落位（620ms 起），
> 这样视觉上是"路线先画出来，景点再一个个落位"。

### 3.2 交互动效

| 交互 | 动效 |
|---|---|
| **点位 hover** | `r` 从 5→8（140ms `ease-out`）+ 旁边滑出一条 **等宽小标签**（名称，从左 `translateX(-4px)` 淡入） |
| **点位 click** | 一个 1px 的圆环从点位**扩散出去**并淡出（420ms）——瑞士风的"打点" |
| **Day tab 切换** | 旧条目整体 `opacity .3` 淡出（120ms）→ 新条目从下 `10px` 上移（260ms stagger 28ms）；底部黑线在标签间滑动（260ms） |
| **事件流抽屉展开** | 抽屉 `translateY(100%)→0`（320ms `cubic-bezier(.32,.72,0,1)`）+ 事件逐条淡入（stagger 16ms） |
| **事件 hover / 当前项** | 左侧 2px 红条 `scaleY 0→1`（180ms）——**不是背景色变化** |
| **预算数字** | `requestAnimationFrame` 从 0 count 到目标值（700ms），配 `tabular-nums` 防抖动 |
| **按钮 hover** | 背景在黑 ↔ 红之间切换（140ms），**不做位移/缩放** |

### 3.3 关键帧与缓动

```css
:root{
  --ease-out:cubic-bezier(.16,1,.3,1);
  --ease-inout:cubic-bezier(.32,.72,0,1);
}
@keyframes riseIn { from{opacity:0;transform:translateY(10px)} to{opacity:1;transform:none} }
@keyframes dropIn { from{opacity:0;transform:translateY(-8px)} to{opacity:1;transform:none} }
@keyframes slideL { from{opacity:0;transform:translateX(-16px)} to{opacity:1;transform:none} }
@keyframes slideR { from{opacity:0;transform:translateX(16px)} to{opacity:1;transform:none} }
@keyframes drawX  { from{transform:scaleX(0)} to{transform:scaleX(1)} }
@keyframes titleIn { from{opacity:0;letter-spacing:-12px} to{opacity:1;letter-spacing:-2.4px} }
@keyframes popIn  { from{opacity:0;transform:scale(.2)} to{opacity:1;transform:scale(1)} }
@keyframes ping   { from{opacity:.8;transform:scale(1)} to{opacity:0;transform:scale(2.6)} }
```

- 元素默认 `opacity:0` + 对应 animation + `animation-fill-mode:both`，延迟用 `animation-delay`
- **stagger 用 CSS 实现，不要改 JS**：
  ```css
  .poi-marker{ animation:popIn .26s var(--ease-out) both; }
  ```
  若要逐个延迟，用 `:nth-child` 写前 N 条，或给 SVG 元素加 `--i` 自定义属性由 JS 写入——
  **但 JS 改动仅限 map.js 里给 marker 加一个 `style.setProperty('--i', idx)`**，
  这是允许的最小改动（不改逻辑，只写一个 CSS 变量）。

### 3.4 降级

```css
@media (prefers-reduced-motion: reduce){
  *,*::before,*::after{
    animation-duration:.01ms!important;animation-delay:0ms!important;
    transition-duration:.01ms!important;scroll-behavior:auto!important;
  }
}
```
